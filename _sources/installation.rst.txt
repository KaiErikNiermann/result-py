Installation
============

Requirements
------------

- Python **3.14** or later

From PyPI
---------

.. code-block:: bash

   pip install fn-result-py

With Poetry
-----------

.. code-block:: bash

   poetry add fn-result-py

From Source
-----------

.. code-block:: bash

   git clone https://github.com/KaiErikNiermann/result-py.git
   cd result-py
   poetry install
